### 2. 🧠 Mini-context

> **CEO:** So — do we commit to the vendor this week?
> **Levi:** Yes. **Unless the board objects**, I'll sign by Friday.
> **CFO:** And the budget?
> **Levi:** You can release the full amount **as long as we hit the Q1 milestones**. If we miss them, it pauses automatically.
> **CFO:** I can live with that — **provided finance signs off on the forecast first**.
> **Levi:** Agreed. And **providing adoption stays above sixty percent**, the second tranche unlocks in Q2.
> **CEO:** So the whole thing is conditional.
> **Levi:** Exactly. Every yes has a string attached — but **as long as the numbers hold**, we're fully committed.

Notice what these linkers do that yesterday's *although / despite* did **not**: they don't concede a fact — they **set a condition**. Each one says *"this will happen — but only if that is true."* *Unless the board objects* = I'll sign, except if they block it. *As long as we hit the milestones* = the budget flows, on that one condition. *Provided finance signs off* / *providing adoption stays high* = the same "only if," in a more formal register. And watch the verbs: *unless the board **objects*** (not *will object*), *as long as we **hit*** (not *will hit*). After every one of these, the future is written in the **present tense** — just like after *if*.

### 3. 📐 A regra (form)

All four linkers introduce a **condition** — something that must be true for the main clause to happen. They are relatives of *if*, and they follow *if*'s grammar exactly.

| Linker | Meaning | Example |
|---|---|---|
| **unless** | **if … not** / except if | *We'll lose the deal **unless** we respond by Friday.* (= if we don't respond) |
| **as long as** | only **on condition that** (condition is essential) | *You can have the budget **as long as** you hit the milestones.* |
| **so long as** | = as long as (slightly more informal) | *It's fine **so long as** nobody misses the deadline.* |
| **provided (that)** | only on condition that (formal) | *The board will approve it **provided (that)** we show audited numbers.* |
| **providing (that)** | = provided that (interchangeable) | *We'll proceed **providing (that)** adoption holds.* |

**The one rule that governs all of them — present tense for future meaning:**
Just like after *if*, you do **not** use *will* in the condition. The present tense already carries the future.
- ✅ *Unless we **respond**, we lose it.* / ❌ *Unless we **will respond**…*
- ✅ *As long as adoption **stays** high, …* / ❌ *As long as adoption **will stay** high…*

**Position & punctuation (same as *if*):** either half can come first. Front → comma; back → usually none.
- *Unless the board objects, I'll sign.* / *I'll sign unless the board objects.*
- *Provided we hit the numbers, the budget releases.* / *The budget releases provided we hit the numbers.*

**The *(that)* is optional:** *provided that we deliver* = *provided we deliver*. Drop it in speech, keep it in a written contract or board memo where it reads cleaner.

### 4. 🎯 Quando usar — e quando não (THE core section)

**Why do these exist?** Yesterday's linkers *conceded* ("this is true, but we win anyway"). These **negotiate** — they attach a **string** to a yes. That is the native grammar of executive life: budgets released *on conditions*, deals signed *unless* someone blocks them, tranches that unlock *provided* a metric holds. A bare *if* states a neutral hypothesis; these words let you signal **exactly what kind of condition** you mean — a dealbreaker exception (*unless*), an essential requirement you're insisting on (*as long as / provided*), or a formal term of agreement (*provided that*). Picking the right one is the difference between sounding like you're guessing and sounding like you're setting terms.

**Decision rule #1 — `unless` = *if … not* (THE trap that flips the sentence):**

*unless* already contains the negative. It means **"if … not" / "except if."** So you **never** add a second *not* inside it.

| You want to say | ✅ with *unless* | ✅ with *if … not* |
|---|---|---|
| We lose the deal if we don't respond. | *We lose the deal **unless we respond**.* | *We lose the deal **if we don't respond**.* |
| The budget pauses if we don't hit the target. | *The budget pauses **unless we hit** the target.* | *The budget pauses **if we don't hit** the target.* |

The two columns say the **same thing**. *unless we respond* = *if we don't respond*. So ❌ *"unless we **don't** respond"* means the opposite of what you intend — it's a double negative (see error #1). **Rule:** after *unless*, write the verb **positive**, because the "not" is already inside the word.

**Decision rule #2 — `as long as / provided` vs plain `if` (condition you *insist on* vs neutral hypothesis):**
- *"**If** we hit the milestones, the budget releases."* → neutral: states one possibility among others.
- *"The budget releases **as long as** we hit the milestones."* → emphatic: the milestones are the **essential condition** — *only on that basis, no exceptions.*
- *"The board will approve it **provided (that)** we show audited numbers."* → formal: this is a **term of the agreement**, the register of contracts and boardrooms.

They all map onto *if*, but they add colour *if* can't: *as long as* / *provided* say *"this is my condition and I'm holding you to it."*

**Decision rule #3 — `as long as / provided` (condition) vs `in case` (precaution):**
This catches people because Portuguese blurs them. They are **opposite logics**.
- *"We'll release the budget **as long as** adoption holds."* → a **condition**: the budget depends on adoption. No adoption, no budget.
- *"Let's keep a reserve **in case** adoption drops."* → a **precaution**: we act **now** to be ready for a *possible* future problem. The reserve isn't conditional on anything — it's insurance.

*as long as / provided* = the thing happens **only if** the condition is met. *in case* = we do something **now** **because** something **might** happen later. Not the same move.

**PT→EN mapping (where translation betrays you):**
- *a não ser que · a menos que* (+ subjuntivo) → **unless** (+ **positive** present): *"a menos que respondamos"* → *"**unless** we **respond**"* — **not** *"unless we don't respond."*
- *desde que · contanto que* (condition) → **as long as / provided (that) / providing (that)**: *"desde que atinjamos as metas"* → *"**as long as** we **hit** the targets."*
- ⚠️ *desde que* has **two faces** in Portuguese: condition (*contanto que* → **as long as / provided**) **and** time (*a partir do momento em que* → **since**). *"desde que entrei na empresa"* = *"**since** I joined"* (time), **not** *as long as*. Choose by meaning, not by the word.
- *caso · para o caso de* → **in case** (precaution), **not** a plain condition.
- The future trap: Portuguese says *"desde que **atingirmos**"* (future subjunctive), so the hand reaches for *will* — but English uses the **present** after all of these (*as long as we **hit***), exactly as after *if*.

**Top 3 typical Brazilian-speaker errors:**
1. ❌ *"**Unless** we **don't** hit the target, the budget pauses."* (double negative) → ✅ *"**Unless** we **hit** the target, the budget pauses"* **or** *"**If** we **don't** hit the target, the budget pauses."* *unless* already means *if not* — never add a second *not*.
2. ❌ *"As long as the board **will approve** it, we'll start hiring."* (future in the condition) → ✅ *"As long as the board **approves** it, we'll start hiring."* After *as long as / provided / unless*, the future is the **present tense** — same rule as *if*.
3. ❌ *"**Since** you deliver on time, I'll release the next tranche."* (using *since* for a condition because of *desde que*) → ✅ *"**As long as** / **Provided** you deliver on time, …"*. *since* in English is **cause or time**, never a condition; *desde que*-as-condition is *as long as / provided*.

### 5. ✏️ 8 annotated examples

1. **Unless the board objects, we commit to the vendor by Friday.**
   *— `unless` = "if the board doesn't object." The verb stays **positive** (`objects`), because the "not" is already inside `unless`. Don't say "unless the board doesn't object."*
2. **You can release the full budget as long as we hit the Q1 milestones.**
   *— `as long as` = the milestones are the **essential** condition; present tense `hit` for future meaning. Stronger than a neutral "if we hit."*
3. **The board will approve the AI raise, provided we present audited numbers.**
   *— `provided` = a **formal** condition, the register of boardrooms and contracts. "provided we present" (present), never "provided we will present."*
4. **Providing adoption stays above sixty percent, the second tranche unlocks in Q2.**
   *— `providing` = interchangeable with `provided`; front position takes a comma. Present tense `stays` carries the future.*
5. **We'll stay ahead of the market as long as we keep investing in the model.**
   *— `as long as` naming the one condition for staying ahead. Not "as long as we will keep" — present after the linker.*
6. **Let's hold a cash reserve in case the funding round slips.** *(contrast item)*
   *— `in case` = **precaution**, not condition: we act **now** because the round **might** slip. Compare "as long as the round closes" (a condition) — opposite logic.*
7. **We won't miss the flight as long as we leave by six.** *(everyday)*
   *— `as long as` = "only on the condition that we leave by six"; present `leave`. "Unless we leave by six, we'll miss it" says the same with the if-not shape.*
8. **You can borrow the car, provided you fill up the tank.** *(everyday)*
   *— `provided` = a plain condition attached to the yes; the `(that)` is dropped in speech. "as long as you fill up the tank" would be identical in meaning.*

Run a **"terms of the yes" round** with your tutor: they ask you to approve something (*a budget, a vendor, a new hire, a pilot extension*) and you must say yes **with a string attached**, cycling through all four linkers — *"**as long as** we hit the milestones," "**provided** finance signs off," "**unless** the board objects, …," "**providing** adoption holds."* The rule to enforce out loud: present tense after every one (**no *will***), and after *unless* the verb stays **positive** (no second *not*). ### 9. ✅ Gabarito

**Warm-up (Unit 115 — *although / despite*):**
1. **although** — *"**Although** the pilot succeeded, the board still wants another quarter."* The part after the blank is a full **clause** (subject *the pilot* + verb *succeeded*), which only a clause linker allows. To make *despite* legal, turn the clause into a **noun**: *"**Despite** the pilot's **success**, …"* (or *"Despite the fact that the pilot succeeded, …"*).
2. **drop the *of* after *despite*, add the *of* after *in spite*:** *"We launched **despite** the delay, **in spite of** a tight budget."* *despite* never takes *of*; *in spite* always does.
3. **drop *but*:** *"**Even though** the results were strong, the board hesitated."* (or *"The results were strong, **but** the board hesitated."*) English uses **one** contrast marker, not both — *even though … but* is the Portuguese *embora … mas* leaking in.

**Spaced review:**
- **Unit 109 (very vs much):** **much** — *"the platform is **much** better."* *better* is a **comparative**, so it needs *much / far / a lot*; *very* only goes with a **base** adjective (*very good*), never a comparative — so *"very better"* simply isn't English.
- **Unit 084 (comparatives 1):** *"Building in-house is **cheaper** and **faster than** licensing."* Three fixes: *more cheap → **cheaper*** and *more fast → **faster*** (short words take *-er*, never *more* — the Portuguese *mais* misleads you), and *that → **than*** (the connector is always *than*, one word).

**Recognition drill:**
1. **Wrong — double negative.** *"Unless we **don't** sign…"* reverses the meaning. Fixes: *"**Unless** we **sign** by Friday, we lose the slot"* **or** *"**If** we **don't** sign by Friday, we lose the slot."* *unless* already = *if not*, so the verb after it stays **positive**.
2. **unless + positive verb:** *"**Unless** finance **signs** off, the deal is dead."* Switching *if … not* to *unless* **removes** the *not* — the negative moves into the word *unless* itself.
3. **hold** — *"…provided the retention numbers **hold**."* After *provided* (like *if / unless / as long as*) the future is carried by the **present tense**; *will* never appears in the condition.
4. **in case** — *"Keep the legacy system running **in case** the migration fails."* It's a **precaution**: we keep it running **now** because the migration **might** fail. *"as long as the migration fails"* would be nonsense here — that would make the failure a *condition* for keeping the system, the opposite of the intended insurance.

### 10. 🇧🇷 Resumo em português

**A regra:** depois de *although / despite* (que **concedem**), estes conectivos **põem condição** — um "sim" com uma corda amarrada. **unless** = *a não ser que / a menos que* (= *if not*, "se não"); **as long as / so long as** = *desde que / contanto que* (condição essencial, enfática); **provided (that) / providing (that)** = *desde que / contanto que* num registro mais **formal** (reuniões de board, contratos). Todos são parentes do *if* e seguem a gramática do *if*: a condição vai no **presente**, nunca com *will* — *"as long as we **hit** the target"* (não *will hit*). O *(that)* é opcional: *provided (that) we deliver*.

**As armadilhas (interferência do português):** (1) *unless* já carrega o "não" — então **não** ponha um segundo *not*: *"unless we **hit** the target"* ✅, nunca *"unless we **don't** hit"* ❌ (isso inverte o sentido). (2) Não use *will* na condição: o português *"desde que **atingirmos**"* (futuro do subjuntivo) puxa o *will*, mas o inglês usa o **presente** (*as long as we **hit***). (3) Cuidado com *desde que*: ele tem **duas** caras — condição (*contanto que* → **as long as / provided**) e tempo (*a partir de quando* → **since**); *"desde que entrei"* = *"**since** I joined"*, não *as long as*. E não confunda **condição** (*as long as / provided* — a coisa só acontece **se**) com **precaução** (*in case* — você age **agora** porque algo **pode** acontecer): são lógicas opostas. Na dúvida, lembre: *unless* = *if not*, e depois de todos eles o futuro vira **presente**.
