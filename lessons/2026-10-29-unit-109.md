### 2. 🧠 Mini-context

> **CEO:** How does the new platform compare to our current stack?
> **Levi:** It's **far more scalable** — and honestly **much cheaper** to run at volume.
> **CFO:** Cheaper by how much?
> **Levi:** Only **a bit less** per seat today, but the gap gets **bigger and bigger** as we grow.
> **CEO:** And speed?
> **Levi:** **Slightly slower** on cold starts — but **the more data we feed it, the better it performs**.
> **CFO:** So the case strengthens with scale.
> **Levi:** Exactly. And **the sooner we commit, the stronger our position** with the vendor.

Notice that nobody just says *"better"* or *"cheaper."* Every comparison carries a **size**: *far more scalable* and *much cheaper* (a big gap), *a bit less* and *slightly slower* (a small one). Then two special shapes appear: *bigger and bigger* (a gap that keeps growing) and *the more… the better* / *the sooner… the stronger* (two things moving together). And watch what never happens: no *"very cheaper,"* no *"very more scalable."* With a comparative, the booster is *much / far / a lot* — never *very*.

### 3. 📐 A regra (form)

You already know the comparative itself (Unit 084): short adjective **+ -er** (*cheaper, faster, bigger*), longer adjective **more + …** (*more scalable, more realistic*), plus the irregulars *better / worse / further*. This unit is about the words you put **in front of** a comparative to say **how big the difference is**, and two fixed patterns.

**The boosters / softeners — all go before a comparative, never before a base adjective:**

| Modifier | Size of difference | Example |
|---|---|---|
| **much · far · a lot** | **big** | *much better · far more scalable · a lot cheaper* |
| **even** | bigger than an already-big gap (often a surprise) | *The second quote was **even higher**.* |
| **a bit · a little · slightly** | **small** | *a bit slower · a little cheaper · slightly more risky* |
| **any** (questions / negatives) | *at all* | *Is it **any** faster? · It isn't **any** cheaper.* |
| **no** | zero difference | *It's **no** better than the old one.* |

> Mental picture: **very** sits in front of a **base** adjective (*very good*); **much / far / a lot** sit in front of a **comparative** (*much better*). They never swap seats.

**The two patterns:**

| Pattern | Means | Example |
|---|---|---|
| **comparative *and* comparative** | a change that **keeps going** | *getting **bigger and bigger*** · ***more and more** expensive* |
| **the + comparative …, the + comparative …** | two things **moving together** (proportional) | ***the sooner** we decide, **the better*** · ***the more** data, **the better** it performs* |

Note the doubling shape: short adjective → *worse and worse*; long adjective → *more and more + adjective* (never *"expensiver and expensiver"*).

### 4. 🎯 Quando usar — e quando não (THE core section)

**Why do these exist?** A bare comparative (*"the platform is better"*) tells the listener there's a difference, but not whether it's a rounding error or a game-changer. For a leader that gap is the whole decision: *"a bit cheaper"* authorises nothing, *"far cheaper"* reopens the budget. These modifiers let you put a **magnitude** on the comparison, and the two patterns let you describe **movement** (a trend) and **trade-offs** (the more of this, the more of that) — the two things strategy talk is made of.

**Decision rule — the rival that catches every Brazilian: *very* vs *much*.**
This is the single most important line in the unit.
- **very** + a **base** adjective → *very good · very fast · very expensive*
- **much / far / a lot** + a **comparative** → *much better · far faster · a lot more expensive*

You cannot cross them. *"very better"* and *"very more scalable"* are simply not English — the same way *"much good"* isn't.

| ❌ wrong | ✅ right | why |
|---|---|---|
| *This plan is **very better**.* | *This plan is **much better**.* | *better* is a comparative → needs *much / far / a lot*, not *very* |
| *It's **much good**.* | *It's **very good**.* | *good* is a base adjective → needs *very*, not *much* |

**Decision rule — big difference vs small difference.**
- **much / far / a lot** = a **big** gap: *"far more scalable"* = not close.
- **a bit / a little / slightly** = a **small** gap: *"a bit slower"* = barely noticeable; pairs naturally with *"basically the same."*
- **even** = there was **already** a big gap, and this is **bigger still** — usually with a note of surprise: *"Our quote was high; theirs was **even higher**."*

Minimal pairs — same comparative, different message:
- *"It's **a bit** more expensive"* (shrug — nearly the same) ≠ *"It's **far** more expensive"* (a real problem).
- *"adoption is **a little** faster this quarter"* (marginal) ≠ *"adoption is **much** faster this quarter"* (a story worth telling the board).

**PT→EN mapping (where translation quietly betrays you):**
- *muito* + comparative → **much / far / a lot**, **never** *very*. *"muito melhor"* → ***much better*** (❌ *very better*); *"muito mais escalável"* → ***far more scalable***.
- *um pouco* → **a bit / a little / slightly**: *"um pouco mais lento"* → *a bit slower*.
- *cada vez mais / cada vez pior* → the **doubling** pattern: *more and more · worse and worse* — **not** *"each time more."*
- *quanto mais…, mais…* → ***the more…, the more…***: *"quanto antes decidirmos, melhor"* → *"**the sooner** we decide, **the better**."*

**Top 3 typical Brazilian-speaker errors:**
1. ❌ *"The new model is **very better** / **very more** efficient."* → ✅ *"**much better** / **far more** efficient."* *muito* in front of a comparative is **much / far / a lot**, never *very*. (This is error #1 — fix this one and you fix half the unit.)
2. ❌ *"It's **more cheaper** / **more faster**."* → ✅ *"It's **cheaper** / **faster**."* Never stack *more* on top of an *-er* word — that's a double comparative. *more* is only for the long adjectives (*more scalable*).
3. ❌ *"**Each time** we wait **more**, the risk is **bigger**."* (literal *cada vez mais*) → ✅ *"**The longer** we wait, **the bigger** the risk"* or *"the risk gets **bigger and bigger**."* Use the two native patterns, not a word-for-word *cada vez*.

### 5. ✏️ 8 annotated examples

1. **The new architecture is far more scalable than our current stack.**
   *— `far` + comparative = a big gap. Not `very more scalable`: with a comparative the booster is far / much / a lot, never very.*
2. **This roadmap is much more realistic than the one we scrapped last quarter.**
   *— `much` + comparative (long adjective → more realistic). `very more realistic` is the classic muito-melhor slip; `much` is the fix.*
3. **With the extra budget, the case for going AI-first gets even stronger.**
   *— `even` = the case was already strong, and this makes it stronger still. It signals "on top of what was already a big difference."*
4. **It's a bit slower on cold starts, but a lot cheaper to run at volume.**
   *— two sizes in one line: `a bit` (small, barely matters) vs `a lot` (big, decisive). Choosing the right one is the message.*
5. **The sooner we commit, the stronger our position with the vendor.**
   *— the proportional pattern: two things rise together (earlier commitment → more leverage). Quanto antes…, melhor. Note both halves take "the + comparative."*
6. **The more data we feed the model, the better it performs.**
   *— same pattern with long + short comparatives; "the more X, the better Y." This is the native shape for quanto mais…, melhor — not "how much more… more."*
7. **The longer we leave this decision open, the harder it gets to walk it back.** *(work / everyday)*
   *— `the longer…, the harder…` = a trade-off that worsens with time. Far cleaner than a literal "each time we wait more."*
8. **Traffic gets worse and worse near the holidays, so we left a lot earlier this year.** *(everyday)*
   *— doubling `worse and worse` = a situation that keeps deteriorating (cada vez pior); `a lot earlier` puts a big size on the comparative.*

### 9. ✅ Gabarito

**Warm-up (Unit 108 — *quite / rather / fairly / pretty*):**
1. **"quite certain"** — there *quite* means **completely**, because *certain* is a **non-gradable / absolute** adjective (you can't be "a bit certain"). In *"quite good,"* *good* is **gradable**, so *quite* means only **moderately**. The adjective type is the whole decision.
2. *"It was **quite a risky** decision"* **or** *"It was **a fairly risky** decision."* *quite* must jump **before** the article (*quite a risky*); you can't put it between *a* and the adjective. *"a quite risky"* is wrong.
3. *rather* adds a note of **disapproval / complaint** — "higher than I'd like." *fairly high* would be a flat, **neutral** measurement; *rather high* tells the listener you're **not pleased** with it.

**Spaced review:**
- **Unit 102:** *"The board was **confused** by the pricing model, but I'm genuinely **interested in** the capability."* The people reporting a feeling take the **-ed** form (*confused*); the fixed preposition after it is **interested in** (never *interested on*). The model itself would be *confusing* (-ing = the cause).
- **Unit 081:** **hard** — *"The team worked **hard** all quarter."* *hard* is the adverb meaning *with effort*. The *-ly* version, *hardly*, means *almost not at all* — so *"worked hardly"* would say the **opposite** (they barely worked).

**Recognition drill:**
1. **much** — *"much better."* *better* is a **comparative**, so it needs *much / far / a lot*; *very* only goes with a **base** adjective (*very good*), never with a comparative — so *"very better"* simply isn't English.
2. Two fixes: **"more cheaper" → "cheaper"** (never stack *more* on an *-er* form — double comparative) and **"more faster" → "faster"** (same error). *more* is only for long adjectives like *more scalable*.
3. **a bit** — *"only **a bit** more expensive."* *a bit* marks a **small** difference, which matches "basically the same / wouldn't block the deal." *far* would mean a **big** gap, contradicting that.
4. Both native forms: proportional → *"**The longer** we delay, **the bigger** the cost"*; doubling → *"the cost gets **bigger and bigger** the longer we delay."* Avoid the literal *"each time we delay more…"* (word-for-word *cada vez mais*).

### 10. 🇧🇷 Resumo em português

**A regra:** o comparativo (Unit 084) diz que **existe** diferença; estas palavras dizem **do tamanho** dela. *much / far / a lot* = diferença **grande** (*much better, far more scalable, a lot cheaper*); *a bit / a little / slightly* = diferença **pequena** (*a bit slower*); *even* = já era grande e ficou **ainda maior** (*even higher*). Todas vêm **antes de um comparativo**. Além disso, dois padrões fixos: a repetição *comparativo and comparativo* = mudança que **não para** (*getting bigger and bigger*, *more and more expensive* = cada vez mais), e *the + comparativo…, the + comparativo…* = duas coisas que **andam juntas** (*the sooner we decide, the better* = quanto antes decidirmos, melhor).

**As armadilhas (interferência do português):** a número 1 é *muito melhor → **very better***. Errado — com comparativo o reforço é **much / far / a lot** (*much better*), nunca *very* (que só vai com adjetivo base: *very good*). Não misture os dois. A número 2 é o comparativo duplo: *more cheaper, more faster* — use só *cheaper / faster*; *more* é apenas para adjetivos longos (*more scalable*). E não traduza *cada vez mais* como *"each time more"*: use *more and more* ou *worse and worse*; nem *quanto mais…* como *"how much more…"*: use *the more…, the more…*. Mapa rápido: *muito* + comparativo → *much / far / a lot*; *um pouco* → *a bit / a little / slightly*; *cada vez mais* → *more and more*; *quanto mais…, mais…* → *the more…, the more…*.
