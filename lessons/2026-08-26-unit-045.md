### 1. 📘 Unit 045 — I went there to… (to for purpose: why you do something)

---

### 2. 🧠 Mini-context

> **CFO:** Why are you flying to Boston on Thursday?
> **You:** I'm going **to close** the vendor deal — and **to meet** their AI
> research lead in person.
> **CFO:** And the extra headcount you asked for?
> **You:** We need two more engineers **to ship** the flagship on time. I brought
> the sensitivity table **to answer** exactly the cost question you'd raise.
> **CFO:** Smart. What's the offsite for?
> **You:** It's **for aligning** the leadership team before we go to the board —
> one room, one story.

Notice the pattern before any rule. Every time you say **why** you do something,
the reason is a bare *to* + verb: *to close*, *to meet*, *to ship*, *to answer*.
Portuguese uses *para* for all of this — and the trap is that *para* also becomes
**for** (before a *noun*: *"for the offsite"*, *"for aligning"*). One Portuguese
word, two English roads. This unit is about picking the right one.

---

### 3. 📐 A regra (form)

To say the **purpose** of an action — *why* you do it — use **to + base verb**:

| Action | Purpose (why) |
|---|---|
| I flew to Boston | **to close** the deal. |
| We need two engineers | **to ship** the flagship. |
| I brought the table | **to answer** the cost question. |
| She called the CFO | **to align** on the number. |

**Key facts:**
- **to + base verb = in order to.** *"I called **to explain**"* = *"I called **in
  order to** explain."* The longer *in order to* / *so as to* is just a more
  formal version of the same thing (useful in writing).
- **Never *for* + verb, never *for to* + verb.** The purpose of an **action** is
  always plain *to* + verb: *"I came **to help**"*, not *"for help"* / *"for to
  help"* / *"for helping."*
- ***for* goes before a NOUN**, not a verb: *"I came **for the meeting**"*,
  *"a room **for the offsite**"*, *"a tool **for analysis**."*
- After some nouns you can use *for* + **-ing** to name a thing's **function**:
  *"a tool **for measuring** adoption"*, *"a room **for aligning** the team."*
  But the reason **you** act is still *to* + verb.
- Negative purpose = *so as not to* / *in order not to*: *"I kept it short **so as
  not to** lose the room."*

---

### 4. 🎯 Quando usar — e quando não (THE core section)

**Why does this structure exist?** Because English needs a clean way to answer the
question *why?* — the purpose behind an action — and it does it with an infinitive:
*to* + verb. For a leader this is constant: you rarely just *do* things, you do
them **in order to** achieve something. *"I flagged the risk **to protect** the
timeline", "We're hiring **to scale** the platform", "I framed it that way **to
win** the board."* The *to*-purpose is the grammar of intention and justification —
the "so that we get X" that sits behind every strategic move.

**Decision rule #1 — *to* + verb vs *for* + noun (the whole game for a
Brazilian).** Portuguese uses **one** word, *para*, for both. English splits it by
what comes next:

| Portuguese | English | Rule |
|---|---|---|
| Vim **para ajudar** | I came **to help** | *para* + **verbo** → **to** + verb |
| Vim **para a reunião** | I came **for the meeting** | *para* + **substantivo** → **for** + noun |
| Uma ferramenta **para medir** | A tool **for measuring** / **to measure** | *para* + função de um objeto → *for* + -ing |

Test: is *para* followed by an **action** (a verb)? → **to** + base verb. Is it
followed by a **thing** (a noun)? → **for** + noun. This single test kills the most
frequent Brazilian purpose error.

**Decision rule #2 — *to* (purpose) vs *for* + -ing (function).** Both can follow a
noun, and the split is subtle:
- **Why *you* did the action** → *to* + verb: *"I built the dashboard **to track**
  adoption."* (your reason for acting)
- **What a *thing* is *for* (its job)** → *for* + -ing: *"a dashboard **for
  tracking** adoption."* (the object's function, no actor)
Minimal pair: *"I use this framework **to prioritize** bets"* (my purpose) vs *"a
framework **for prioritizing** bets"* (the framework's function). When *you* are the
one acting, default to *to* + verb.

**Decision rule #3 — *to* + verb vs *because* (reason).** *to* answers **what
for / what goal**; *because* answers **what caused it (the past reason)**:
- *"I flew to Boston **to close** the deal."* → goal ahead of me. ✅
- *"I flew to Boston **because** the deal was slipping."* → cause behind me. ✅
Don't blur them: *"I flew **for close** the deal"* is neither — it's the *para*
interference again.

**PT→EN mapping — where Portuguese betrays Levi.** (1) *para* + verbo → *to* +
verb, **never** *for* + verb and **never** *for to*. (2) *para* + substantivo →
*for* + noun. (3) *"o que é isso para?"* → *"what is this **for**?"* (the *for*
lands at the **end**), not *"for what is this?"*.

**Top Brazilian-speaker errors:**
- ❌ *"I called the CFO **for align** on the budget."* → ✅ *"I called the CFO **to
  align** on the budget."* — purpose of an **action** is *to* + verb, never *for*
  + verb.
- ❌ *"We hired a consultant **for to review** the AI strategy."* → ✅ *"We hired a
  consultant **to review** the AI strategy."* — there is no *for to*; *to* alone
  carries "in order to."
- ❌ *"I'm here **to the meeting**."* → ✅ *"I'm here **for the meeting**."* —
  before a **noun** (*the meeting*), the word is *for*, not *to*.

### 5. ✏️ 8 annotated examples

1. *"I'm flying to Boston **to close** the vendor deal and **to meet** their AI
   lead."*
   *— to + verb = the purpose of the trip. Two goals, each its own "to". "For close" would be the classic para-interference error.*
2. *"We need two more engineers **to ship** the flagship on time."*
   *— purpose after a noun (engineers): why we need them. Not "for ship", not "for shipping" — the actor's reason is to + verb.*
3. *"I brought the sensitivity table **to answer** the exact cost question the CFO
   would raise."*
   *— to + verb states intent: I brought it in order to answer. Rival "because the CFO asked" would give the past cause, not the goal.*
4. *"We're positioning the company as AI-first **to win** enterprise deals before
   competitors move."*
   *— strategic justification: the "so that we get X" behind the move, packed into to + verb.*
5. *"The offsite is **for aligning** the leadership team before the board meeting."*
   *— for + -ing names the event's function (what the offsite is for). Contrast ex. 6: when YOU act, it flips to "to".*
6. *"I called the offsite **to align** the leadership team before the board."*
   *— same idea, but now I'm the actor stating my purpose → to + verb. "for align" is impossible.*
7. *"I kept the deck to three slides **so as not to** lose the board's attention."*
   *— negative purpose: "so as not to" / "in order not to" is how you say "para não…". Never "for not lose".*
8. *"I stopped at the pharmacy **to pick up** a prescription on the way home."*
   *— everyday life, same engine: to + verb = why I stopped. "para pegar" → "to pick up", not "for pick up" / "for to pick up".*

### 8. 🗣️ Para levar para a aula

- Ask your tutor to run a **"why drill"**: they fire *why* questions at you about
  your real week — *"Why are you meeting the CFO? Why hire two engineers? Why the
  offsite? Why the three-slide deck?"* — and you must answer instantly with **to +
  verb** (*"To align on the budget", "To ship the flagship", …*). The goal is to
  make the *to*-purpose automatic so *"for align"* never surfaces in a real room.
- Then a **para-splitter**: have your tutor read Portuguese *para*-phrases mixing
  verbs and nouns — *"para fechar o deal", "para a reunião de board", "uma
  ferramenta para medir adoção", "para não perder o timing"* — and you render each
  live, choosing **to + verb**, **for + noun**, **for + -ing**, or **so as not
  to**. This trains the one decision Brazilians most often get wrong.

### 9. ✅ Gabarito

**Warm-up (Unit 044 — Verb + object + to…):**
1. ***"The board expects us to deliver** a single flagship bet."* — English has no
   *want/expect that…*; the *que*-clause becomes **object (us) + to + base verb
   (deliver)**.
2. ***made us cut*** — *make* (= force) takes the **bare** infinitive: *made us
   **cut***, no *to*. Swap in *allow* and *to* returns: *"allowed us **to cut**."*
   (*let/make* drop *to*; *allow/enable/get* keep it.)
3. ***told*** — *"The CEO **told me to** lead the roadmap."* A **person** right
   after the verb forces *tell/ask* (+ *to*); *say* takes **no object** and a
   *that*-clause, so *"said me to"* is impossible.

**Spaced review:**
- **(Unit 038)** ***"Let's** keep the board deck to three slides."* — *Let's* +
   base verb rallies the room to act **together**; the negative is ***Let's not***
   + verb: *"**Let's not** guess on cost."* (not *"Don't let's…"* / *"Let's don't…"*).
- **(Unit 017)** ***"Have** you **ever** led a company-wide AI transformation
   before?"* — present perfect *have + past participle* scans your **whole career
   up to now**; ***ever*** sits **between the subject and the participle**
   (*have you **ever** led*).

**Recognition drill:**
1. ***"…flew to Singapore **for** the regional AI summit, and **to** recruit a
   country lead."*** — *for* before the **noun** (*the summit*); *to* before the
   **verb** (*recruit*). What comes next — thing or action — decides the word.
2. ***to*** — *"…an advisor **to challenge** our 2027 roadmap."* *for* + verb and
   *for to* + verb are both impossible; plain *to* alone means "in order to."
3. First blank → ***for prioritizing*** (*"a framework **for prioritizing**…"* =
   the framework's **function**, no actor). Second → ***to prioritize*** (*"We use
   the framework **to prioritize**…"* = **your** purpose in acting). When *you* act,
   it's *to* + verb.
4. **Wrong: *for discuss*** (no *for* + verb, no *for to*). Two fixes: verb →
   *"I'm here **to discuss** the AI budget"*; noun → *"I'm here **for the
   discussion** about the AI budget."*

### 10. 🇧🇷 Resumo em português

**A regra e quando usar.** Para dizer **por que** você faz algo — o propósito de uma
ação — o inglês usa **to + verbo na base**: *"I flew to Boston **to close** the
deal", "We need engineers **to ship** the flagship", "I brought the table **to
answer** the cost question."* É o *para* + verbo do português: *para fechar* → *to
close*. A versão formal é *in order to* / *so as to* (mesma ideia); o negativo
(*para não…*) é *so as not to* / *in order not to*. Use sempre que for justificar
uma ação, dar a intenção ou o objetivo por trás de um movimento — o "para conseguir
X" que sustenta toda decisão estratégica.

**As armadilhas.** O erro nº 1 nasce de *para* ter **dois** caminhos em inglês: (1)
*para* + **verbo** vira **to** + verbo — **nunca** *for* + verbo, **nunca** *for to*
(*"for align"*, *"for to review"* estão errados; use *"to align", "to review"*).
(2) *para* + **substantivo** vira **for** + substantivo (*"I'm here **for the
meeting**"*, não *"to the meeting"*). O teste: depois do *para* vem uma **ação**
(verbo)? → **to** + verbo. Vem uma **coisa** (substantivo)? → **for** + substantivo.
E cuidado com *para* de **função de um objeto**, que vira *for* + -ing (*"a tool
**for measuring** adoption"*) — mas quando **você** é quem age, volta para *to* +
verbo (*"I built it **to measure** adoption"*). Se a mecânica de verbo + verbo ainda
embolar, releia `lessons/2026-08-25-unit-044.md` (Verb + object + to) — é o par
direto desta unidade.
