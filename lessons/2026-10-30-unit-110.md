### 1. 📘 Unit 110 — comparisons of equality: *as … as · not as … as · the same as*

### 2. 🧠 Mini-context

> **CEO:** Is this challenger a real threat, or are we overreacting?
> **Levi:** Their model is **almost as accurate as** ours — but it's **nowhere near as expensive** to run.
> **CFO:** So they match us on quality?
> **Levi:** Not quite. They're **not as mature as** we are on security. But their pricing isn't **the same as** last year's — they've cut it hard.
> **CEO:** And our own roadmap?
> **Levi:** It costs **about the same as** the plan we already approved — but it won't move **as fast as** the board wants.

Notice three shapes doing three different jobs. ***as* + adjective + *as*** (*as accurate as*, *as fast as*) says the two things are **equal** on that quality. The **negative** — *not as mature as*, *nowhere near as expensive* — says one **falls short** of the other. And ***the same as*** (*the same as last year's*) says they **match**. Watch two things that never happen: no *"as **more** accurate as,"* no *"the same **than** last year."* The adjective inside *as … as* stays in its **base** form, and *the same* is always followed by ***as***.

---

### 3. 📐 A regra (form)

Three related structures for saying things are equal (or not):

| Structure | Means | Example |
|---|---|---|
| **as + [base adjective/adverb] + as** | A and B are **equal** on this quality | *Their model is **as accurate as** ours.* |
| **not as + [base] + as** | A is **less** than B (= a comparative with *less*) | *It's **not as expensive as** the incumbent.* (= cheaper) |
| **the same as** | A and B **match** | *Our costs are **the same as** last year's.* |

**Key facts:**
- The word inside *as … as* is the **base** form — *as cheap as*, *as good as*, *as fast as* — **never** a comparative. ❌ *as cheaper as*, ❌ *as better as* are impossible.
- *not as … as* is the everyday way to say *less … than*. *"not as expensive as"* = *"less expensive than"* = *"cheaper than"* — same meaning, softer framing.
- **Size words go in front of the first *as*:** *just* as fast, *almost* as fast, *nearly* as fast, *not nearly* as fast, *nowhere near* as fast, *twice* as fast, *half* as fast, *three times* as fast.
- **the same** is always followed by ***as*** — never *than*, never *of*. *"the same as last year,"* *"the same price as ours."*
- After *as … as* a pronoun can be *as tall as me* (spoken/natural) or *as tall as I am* (full form). Both fine.

---

### 4. 🎯 Quando usar — e quando não (THE core section)

**Why does this structure exist?** A comparative (*"their model is more accurate"*) says the two are **different** and ranks them. *as … as* does the opposite job: it says they are **level** — equal, matched, neck-and-neck. And its negative is the most useful part of all: *"not as accurate as ours"* says one falls short **while keeping your own thing as the reference point**. For a leader that framing matters — *"the challenger isn't as mature as we are"* keeps you as the benchmark; *"the challenger is less mature"* just ranks them. Same facts, different center of gravity.

**Decision rule — *not as … as* vs the comparative (*less … than* / *-er than*).**
They can state the **same fact**, so the choice is about framing:
- *"Option A is **not as expensive as** Option B."* → keeps **B** as the yardstick; A is measured against it. (Softer, more diplomatic.)
- *"Option A is **cheaper than** Option B."* / *"**less expensive than** B."* → a flat ranking.

Both tell you A costs less. Use *not as … as* when you want the reference point (often *ours*, *the plan we approved*) to stay in focus.

Minimal pairs — equal vs ranked:
- *"Their platform is **as scalable as** ours."* (dead level) ≠ *"Their platform is **more scalable than** ours."* (they win) ≠ *"Their platform is **not as scalable as** ours."* (we win).
- *"This quarter was **as strong as** last quarter."* (matched) ≠ *"This quarter was **not as strong as** last quarter."* (weaker).

**the same as vs the rival spellings.** *the same* locks onto ***as***. The comparison partner of *different* is *from/to* (*different **from** ours*), but *same* only ever takes *as*:
- ✅ *"the same as last year"* — ❌ *"the same **than** last year,"* ❌ *"the same **of** last year,"* ❌ *"the same **that** last year."*

**PT→EN mapping (where translation quietly betrays you):**
- *tão … quanto / tão … como* → **as … as**: *"tão caro quanto o atual"* → *as expensive as the current one*. The Portuguese *tão* becomes the **first** *as* — don't drop it (❌ *"expensive as ours"*).
- *não tão … quanto* → **not as … as**: *"não é tão maduro quanto nós"* → *not as mature as we are*.
- *o mesmo que / a mesma coisa que* → **the same as** (never *the same than* — Portuguese *que* tempts you into *than*).
- *duas vezes mais … que* → **twice as … as**: *"duas vezes mais rápido que"* → *twice as fast as* (not *"two times more fast than"*).

**Top 3 typical Brazilian-speaker errors:**
1. ❌ *"Our costs are **the same than** last year"* / *"**the same of** last year."* → ✅ *"**the same as** last year."* *same* only takes **as** — the Portuguese *mesmo **que*** pulls you toward *than/of*. (This is error #1 — *same* + *as*, always.)
2. ❌ *"Their model is **as more accurate as** ours"* / *"**as better as** ours."* → ✅ *"**as accurate as** ours"* / *"**as good as** ours."* Inside *as … as* the adjective is **base** form — never a comparative. If you want the comparative, drop the *as … as*: *"more accurate **than** ours."*
3. ❌ *"Their pricing is **so aggressive as** ours"* or dropping the first *as*: *"their pricing is **aggressive as** ours."* → ✅ *"**as aggressive as** ours."* You need **both** *as*'s; *so … as* is archaic and only ever appears in heavy negatives — in modern English it's *as … as*.

### 5. ✏️ 8 annotated examples

1. **The challenger's model is almost as accurate as ours, but far cheaper to run.**
   *— `almost as … as` = nearly level on accuracy. The size word `almost` sits before the first `as`; the adjective stays base (`accurate`, never `as more accurate as`).*
2. **They're not as mature as we are on security, so I'd stage the migration.**
   *— `not as … as` says they fall short while keeping us as the benchmark. Cleaner than "they are less mature"; note "as we are" (full form) — "as us" is equally fine.*
3. **Running the new stack costs about the same as the plan we already approved.**
   *— `the same as` = a match, with `about` softening it to "roughly." Never "the same than the plan" — same always takes as.*
4. **This roadmap won't scale as fast as the board expects — I need to reset the timeline.**
   *— negative of as … as with an adverb (`as fast as`). Says the speed falls short of expectation; the reference point (what the board expects) stays in view.*
5. **The new vendor is nowhere near as expensive as the incumbent.**
   *— `nowhere near as … as` = a big shortfall (emphatic "not remotely as"). The native way to say "muito menos caro" without a comparative.*
6. **Our margins are twice as high as the industry average, and the board knows it.**
   *— the multiplier pattern: `twice as … as`. Portuguese "duas vezes mais altas que" → "twice as high as", not "two times more high than."*
7. **This espresso isn't as strong as the one I make at home.** *(everyday)*
   *— not as … as for a plain comparison; "isn't as strong as" = weaker than, with the home version as the reference.*
8. **She's not as tired as she looks after that red-eye flight.** *(everyday)*
   *— "not as tired as she looks" — comparing the real state to the appearance; base adjective `tired` inside the as … as frame.*

### 9. ✅ Gabarito

**Warm-up (Unit 109 — strengthening comparatives):**
1. *very* breaks because *better* is a **comparative**, and *very* only goes in front of a **base** adjective (*very good*). The three words that strengthen a comparative are **much / far / a lot** → *"much better / far better / a lot better."* (*even* works too, for "bigger still.")
2. *"a bit more expensive"* authorises nothing — it's a shrug, basically the same. *"far more expensive"* is the one that **reopens the budget** — a big, decisive gap. The size word carries the whole message.
3. (a) *"**The sooner** we decide, **the better**"* — the proportional *the …er, the …er* pattern. (b) *"The competition is getting **more and more aggressive**"* — the doubling pattern (*cada vez mais* → *more and more*), never *"each time more aggressive."*

**Spaced review:**
- **Unit 103:** *"The pilot **went well** and the early results **look good**."* *go* is an **action verb** → adverb **well** (never "went good"); *look* is a **linking verb** → adjective **good** (it describes the results, not an action).
- **Unit 077:** **interested** — *"I'm very **interested in** the AI partnership."* You **have the feeling** → the *-ed* form (plus its fixed preposition *in*). The wrong *interesting* would say **you yourself are a fascinating object** — the opposite of what you mean.

**Recognition drill:**
1. **as good as** — *"Their solution is **as good as** ours."* Inside *as … as* the adjective is **base** (*good*); *"as better as"* is impossible because *better* is already a comparative — you can't put *as … as* around it. (If you want *better*, drop the frame: *"better than ours."*)
2. **the same as** — *"Our run costs are **the same as** last year."* *same* is always followed by **as**, never *than* (the Portuguese *mesmo que* is what pulls you to *than*).
3. **Option A is cheaper.** *"not as expensive as"* = *less expensive than* = cheaper. As a comparative: *"Option A is **cheaper than** Option B"* / *"**less expensive than** Option B."*
4. (a) *"The challenger is **cheaper than** us."* (b) *"The challenger is **not as** expensive **as** us."* Same fact, two shapes: comparative uses *-er + than*; the equality frame negates *as … as* with a **base** adjective.

### 10. 🇧🇷 Resumo em português

**A regra:** três estruturas para dizer que as coisas são **iguais** (ou não). ***as* + adjetivo *base* + *as*** = igualdade (*"as accurate as ours"* = tão preciso quanto o nosso). O **negativo** *not as … as* diz que uma **fica aquém** da outra, mantendo a outra como referência (*"not as mature as we are"* = não tão maduro quanto nós) — é a forma do dia a dia de dizer *less … than*. E ***the same as*** = **coincide** (*"the same as last year"* = o mesmo que ano passado). Palavras de tamanho vão **antes** do primeiro *as*: *just / almost / nearly / nowhere near / twice as … as*.

**As armadilhas (interferência do português):** a número 1 é *o mesmo **que** → "the same **than / of**"*. Errado — *same* só aceita **as** (*the same as*). A número 2: dentro de *as … as* o adjetivo é **base**, nunca comparativo — ❌ *as better as / as more accurate as* → ✅ *as good as / as accurate as* (se quiser o comparativo, tire o *as … as*: *better than*). A número 3: precisa dos **dois** *as* — não diga *"so good as"* nem solte o primeiro (*"expensive as ours"*); é sempre *as … as*. Mapa rápido: *tão … quanto* → *as … as*; *não tão … quanto* → *not as … as*; *o mesmo que* → *the same as*; *duas vezes mais … que* → *twice as … as*.
