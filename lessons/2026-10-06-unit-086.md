### 1. 📘 Unit 086 — equality & difference: *as … as* / *not as … as* / *the same as*

---

### 2. 🧠 Mini-context

> **CEO:** Is the in-house build really behind the vendor now?
> **You:** Honestly, it's **not as far behind as** we feared. On accuracy it's **just as good as** their model —
> the gap is only in speed.
> **CFO:** And cost?
> **You:** Roughly **the same as** last year's budget. It's **not as expensive as** the licensing deal, but
> it's **not as predictable**, either.
> **CEO:** So the two options aren't equal.
> **You:** No. They cost **about the same**, but they're **not the same as** each other in risk. The build is
> **nearly as fast as** the vendor — *nearly*, not *quite*.

Notice a new shape sitting next to last week's comparatives. Instead of ranking one **above** another with
*-er … than*, these sentences measure how **close** two things are. *Just as good as*, *as fast as* say they're
**equal**; *not as expensive as*, *not as far behind as* say one falls **short** of the other; *the same as*,
*the same budget as* say they **match**. The frame is always **as … as** (with an adjective in the middle) or
**the same as** (with a noun). And watch the join: it's **as**, not *than* — *than* belongs to the comparatives,
*as* belongs here.

---

### 3. 📐 A regra (form)

Three related frames for saying how two things measure up:

| Meaning | Frame | Example |
|---|---|---|
| **equal** | *as* + **adjective/adverb** + *as* | *The build is **as accurate as** the vendor's.* |
| **not equal (falls short)** | *not as* + adj/adv + *as* | *It's **not as fast as** theirs.* |
| **identical / matching** | *the same (noun) as* | *Roughly **the same budget as** last year.* |

- The middle word is the **base** adjective — never the *-er* / *more* form: *as **fast** as* ✅, *as ~~faster~~
  as* ❌.
- **Boosters** go in front: *just as good as* (exactly equal), *nearly / almost as fast as* (close but below),
  *not quite as cheap as* (a little below), *twice as expensive as* (a multiple).
- *the same* takes a **noun**, not an adjective: *the same **price** as* ✅, *the same ~~cheap~~ as* ❌.
- After *as* / *the same as* you can use a pronoun (*as fast as **them** / as **they are***), a noun (*as the
  vendor*), or a clause (*the same as **we forecast***).

---

### 4. 🎯 Quando usar — e quando não (THE core section)

**Why does this structure exist?** Comparatives (*-er … than*) rank one thing **above** another. But a huge
amount of executive talk isn't about *which is bigger* — it's about *are these two the same, or how far apart
are they?* *As … as* and *the same as* are the tools for **equality and distance**: "we're on par," "we fell
short," "it matches last year." Nothing else carries *equal* as cleanly.

**Decision rule vs the rival (*-er … than*):**

| You mean… | Use | Example |
|---|---|---|
| A is **above** B | comparative + *than* | *Their model is **faster than** ours.* |
| A **equals / matches** B | *as … as* / *the same as* | *Ours is **as accurate as** theirs.* |
| A **falls short of** B (softer than "B is better") | *not as … as* | *Ours is **not as fast as** theirs.* |

Minimal pair — same facts, different spin:
- *Their model is **better than** ours.* → blunt: they win.
- *Ours is **not as good as** theirs.* → same meaning, **politer**, keeps you in the frame. Executives reach
  for *not as … as* constantly because it concedes a gap without declaring defeat.

**PT→EN mapping:**
- *tão … quanto / tão … como* → **as … as**. *"Tão rápido quanto"* = *as fast as*. The shape maps cleanly —
  the trap is the **join word** (see errors).
- *o mesmo que / a mesma coisa que* → **the same as**. *"O mesmo orçamento que o ano passado"* = *the same
  budget **as** last year*.
- *não é tão caro quanto* → **not as expensive as** — direct and reliable.

**Top Brazilian-speaker errors:**
1. ❌ *"It's as fast **than** the vendor."* / *"the same **than** last year"* → ✅ *as fast **as** / the same
   **as**.* Portuguese *quanto/que* tempts you toward *than*, but *as … as* and *the same* always take **as**.
   *Than* is only for *-er / more* comparatives.
2. ❌ *"It's **so** expensive **as** the deal."* → ✅ *It's **as** expensive **as** the deal.* In statements the
   first word is **as**, not *so*. (*So … as* survives only in old negatives; don't use it.)
3. ❌ *"It costs **the same like** last year."* / *"the same **of** last year"* → ✅ *the same **as** last year.*
   *The same* never pairs with *like* or *of* — only **as**.

### 5. ✏️ 8 annotated examples

1. **On accuracy, our model is just as good as the vendor's — the gap is only latency.**
   *as … as = we're on par; the booster* just *makes it "exactly equal," stronger than a bare comparative.*
2. **The in-house build is not as expensive as licensing, but it's not as predictable, either.**
   *not as … as (twice) concedes two gaps politely — softer than "licensing is cheaper and safer than the build."*
3. **This year's innovation budget is roughly the same as last year's.**
   *the same as + noun (budget) states a match; a comparative can't say "equal" — only above or below.*
4. **The board wants the 2027 vision presented as clearly as the 2026 one was.**
   *as + adverb (clearly) + as compares how an action is done, not a thing — equality of manner.*
5. **Scaling the pilot won't be as hard as everyone assumes.**
   *not as … as downplays a fear — "less hard than people think," but framed as falling short of the worry.*
6. **The new CFO is just as data-driven as her predecessor.**
   *as … as for people; just as = exactly on the same level — a peer comparison, not a ranking.*
7. **We shipped the roadmap almost as fast as we forecast — almost, not quite.**
   *almost as … as = close but below; the clause after as (we forecast) replaces a noun.*
8. **The two vendors quote about the same price, but they're not the same as each other on support.**
   *the same price as = matching figure; not the same as = different — "the same" flips to difference with "not."*

### 9. ✅ Gabarito

**Warm-up (Unit 084):**
1. *scalable* → **more scalable** (long word → *more*); *big* → **bigger** (CVC → double the *g*); *risky* →
   **riskier** (ends in *-y* → *-ier*). Length and spelling of the base word decide the shape.
2. *good* → **better**, *bad* → **worse** — irregular, no *-er* or *more*. You used **better**: *"which is the
   **better** bet?"*
3. **than** joins the two sides (*faster **than** the board expects*). Portuguese speakers wrongly reach for
   *that* or *of* — but a comparative only takes **than**.

**Spaced review:**
- **Unit 079:** ✅ *"The numbers **sound optimistic**."* After *look / feel / sound / seem* you use an
   **adjective**, not an *-ly* adverb — these verbs describe the subject, not the action, so *optimistically* is
   wrong.
- **Unit 056:** **rule out** — *"we need to **rule out** the two vendors."* The particle **out** keeps
   signalling *make fully clear, finish, or remove* across *mapped out / spelled out / ruled out*.

**Recognition drill:**
1. **as** — *as accurate **as** theirs.* Equality frame takes *as*, never *than*.
2. **(b)** *not as good as theirs* — same meaning as "worse than," but concedes the gap politely.
3. **as** — *the same **as** last year.* *The same* pairs only with *as* (never *than / like / of*).
4. **hard** (not *harder*) — *as … as* takes the **base** adjective, never the comparative form.

### 10. 🇧🇷 Resumo em português

Esta unidade é sobre **igualdade e distância**, não sobre ranking. Use **as … as** com um adjetivo no meio para
dizer que duas coisas são iguais (*as fast as* = tão rápido quanto) e **not as … as** para dizer que uma fica
**aquém** da outra — é o jeito educado de admitir uma desvantagem sem dizer "o deles é melhor". Para dizer que
dois valores **coincidem**, use **the same as** + substantivo (*the same budget as last year*). Reforços úteis:
*just as* (exatamente igual), *nearly / almost as* (quase, mas abaixo), *twice as* (o dobro).

A armadilha número um é a **palavra de ligação**: *tão … quanto* e *o mesmo que* puxam você para **than**, mas
aqui é sempre **as** — *than* pertence só aos comparativos *-er / more*. Cuidado também com três erros de
interferência: não comece a frase com *so* (*so expensive as* ❌ → *as expensive as* ✅); nunca use *the same
**like*** nem *the same **of*** (só *the same **as***); e, no meio de *as … as*, use o adjetivo **base**, nunca
a forma comparativa (*as **hard** as* ✅, *as ~~harder~~ as* ❌).
