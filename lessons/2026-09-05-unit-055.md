### 2. 🧠 Mini-context

> **CEO:** Where are we on the AI rollout?
> **You:** We **carried out** the pilot last month, and the results **back up** the thesis.
> I want to **roll it out** to two more business units in Q1.
> **CFO:** I'd **push back on** that. Let's not **scale it up** until we've **looked into**
> the cost per seat.
> **You:** Fair. Let's **follow up on** the numbers this week, then **bring** the decision
> **forward** to the next board.
> **CEO:** Good. And don't let one nervous quarter make us **call** the whole thing **off**.

Notice the pattern before any rule. *carried out*, *back up*, *roll it out*, *push back on*,
*scale it up*, *looked into*, *follow up on*, *bring forward*, *call off* — each is a
**verb + a small word** (*out, up, on, into, off, forward*) that together mean something a
single verb would say more stiffly (*implement, support, launch, resist, expand,
investigate, monitor, advance, cancel*). Two things are doing work here: **which** phrasal
verb sounds native, and **where the object goes** (*roll it out*, never *roll out it*).
That's today's whole lesson.

---

### 3. 📐 A regra (form)

A **phrasal verb** = **verb + particle** (a small word like *up, out, off, on, in, down,
back, forward*). The particle changes the meaning: *look* ≠ *look into* ≠ *look after* ≠
*look up*. There are three types, and the type decides **where an object can sit**:

| Type | Object? | Word order | Example |
|---|---|---|---|
| **Intransitive** | no object | fixed — nothing splits it | *The deal **fell through**.* / *The CEO **stepped down**.* |
| **Transitive — separable** | takes an object | noun goes **either side**; **pronoun MUST go in the middle** | *carry **out** the plan* / *carry the plan **out*** / *carry **it** out* ✅ — *carry out **it*** ✗ |
| **Transitive — inseparable** | takes an object | object **always after** the particle — never splits | *look **into** the numbers* / *look **into** them* ✅ — *look **them** into* ✗ |

**The load-bearing rule (separable verbs):**
- A **noun** object is relaxed — either side works: *"roll out the product"* = *"roll the
  product out."*
- A **pronoun** object (*it, them, us, this*) is strict — it **must** sit **between** verb
  and particle: *"roll **it** out"* ✅, never *"roll out **it**"* ✗.

**How to tell separable from inseparable?** Rough guide: if the little word is a true
**preposition that needs an object** (*into, on, after, for, with*), the verb is usually
**inseparable** (*look into it, count on it, deal with it, push back on it*). If it's an
**adverb-like particle** (*out, up, off, down, away, back*), the verb is usually
**separable** (*carry it out, call it off, turn it down, scale it up*). When unsure, put a
**noun** object after the particle — that's always safe.

### 4. 🎯 Quando usar — e quando não (THE core section)

**Why do phrasal verbs exist — and why care?** They're how English *actually* speaks. In a
meeting a native says *put the launch off*, *call the deal off*, *roll the plan out*, *cut
back on spend* — not *postpone, cancel, implement, reduce*. Both are correct, but they live
in **different registers**: the phrasal verb is the natural, spoken, boardroom-conversation
default; the single Latinate verb is heavier and more formal/written. Miss phrasal verbs
and your English stays grammatically perfect but sounds like a translated document — exactly
the "stiff" impression an executive wants to avoid in a live room.

**Decision rule — phrasal verb vs its single-word (Latinate) rival.** Ask: *am I speaking
or writing formally?*

| You mean | Native in **speech / meetings** (phrasal) | Formal **writing / board docs** (Latinate) |
|---|---|---|
| postpone | *put it off / push it back* | *postpone / defer* |
| cancel | *call it off* | *cancel* |
| implement | *carry it out / roll it out* | *implement / execute* |
| investigate | *look into it* | *investigate / examine* |
| reduce | *cut back on it* | *reduce / curtail* |
| reject | *turn it down* | *reject / decline* |
| support | *back it up* | *support / substantiate* |

Both columns are correct — the trap is using **only** the right-hand column and sounding
like a memo when you're talking. Minimal pair, same idea, different feel:
- *"We should **postpone** the rollout and **investigate** the cost model."* → correct, but
  reads like a written report.
- *"Let's **put the rollout off** and **look into** the cost model."* → the same message, but
  it sounds like a person in the room.

**PT→EN mapping — where the translation betrays Levi.** Portuguese has almost **no phrasal
verbs**; it uses single verbs (*implementar, adiar, cancelar, investigar, reduzir*). That
creates two problems: (1) the reflex reaches for the **Latinate cognate** — *implement,
postpone, cancel* — because it looks like the Portuguese word, so you sound formal by
accident; (2) when you *do* try a phrasal verb, Portuguese gives no instinct for **where the
pronoun goes**, so *"adiá-lo"* becomes *"put off it"* ✗ instead of *"put it off"* ✅. The
grammar, not the vocabulary, is the real trap.

**Top Brazilian-speaker errors:**
- ❌ *"The board hasn't **carried out it** yet."* → ✅ *"…hasn't **carried it out** yet."* —
  separable verb + **pronoun** = the pronoun **must split** the verb and particle. *"Carry
  out it"* is the number-one word-order slip.
- ❌ *"We'll **look them into** before the vote."* → ✅ *"We'll **look into them** before the
  vote."* — *look into* is **inseparable**; the object (noun or pronoun) **never** goes in
  the middle. Don't over-apply the "split" rule from separable verbs.
- ❌ (stiff, in a live standup) *"We must **postpone** the launch and **cancel** the pilot."*
  → ✅ *"Let's **put the launch off** and **call the pilot off**."* — not a grammar error, a
  **register** one: in the room, the phrasal verbs sound native; save *postpone/cancel* for
  the written brief.

### 5. ✏️ 8 annotated examples

1. *"We **carried out** the pilot in Q1 and plan to **roll it out** globally by Q3."*
   *— separable: "carried out the pilot" (noun after particle) is fine, but with the pronoun it MUST split → "roll it out", never "roll out it". Both beat the stiff "implement/launch it".*
2. *"Let's **put** the board decision **off** until we see October's numbers."*
   *— separable, noun splitting the verb: "put the decision off" = "put off the decision". More natural in the room than "postpone the decision".*
3. *"We had to **call** the vendor negotiation **off** after the terms slipped."*
   *— call off = cancel; in live speech the phrasal verb sounds native where "cancel" sounds like a written notice.*
4. *"The CFO **pushed back on** the AI budget, so we staged it."*
   *— inseparable (push back ON): the object follows the whole thing — "pushed back on it", never "pushed it back on". The rival "resisted/objected to" is heavier.*
5. *"I'll **follow up on** the forecast with the chair after the offsite."*
   *— inseparable: follow up on + thing (or follow up WITH a person). "Follow up on it", not "follow it up on".*
6. *"We can't **count on** last year's forecast for a market this volatile."*
   *— inseparable count on = rely on; pronoun stays after → "count on it", never "count it on".*
7. *"My alarm **went off** at six and I still made the strategy call."*
   *— everyday, intransitive: no object, nothing to place. "Went off" = sounded/rang; a single verb ("rang") would lose the idiom.*
8. *"Can you **turn** the music **down**? / Can you **turn it down**?"*
   *— everyday, separable: noun either side, but pronoun splits → "turn it down", never "turn down it". Same rule as the executive ones.*

### 8. 🗣️ Para levar para a aula

- Ask your tutor to run a **"Latinate → phrasal swap" drill** in your world: they fire the
  formal verb from a memo (*"postpone the rollout"*, *"cancel the pilot"*, *"implement the
  roadmap"*, *"investigate the cost"*, *"reduce spend"*, *"reject the proposal"*) and you
  answer instantly with the natural spoken phrasal verb (*put it off, call it off, roll it
  out, look into it, cut back on it, turn it down*). Goal: stop defaulting to the cognate in
  the room.
- Then a **pronoun-placement round**: the tutor gives a phrasal verb + a pronoun and you say
  the correct order, mixing separable and inseparable — *"carry out + it"* → *carry it out*;
  *"look into + them"* → *look into them*; *"call off + it"* → *call it off*; *"count on +
  them"* → *count on them*. This is where *"put off it"* finally dies.

### 9. ✅ Gabarito

**Warm-up (Unit 054 — have):**
1. ***"We have a strong AI team"*** can take **have got** (*"We've got a strong team"*) —
   it's **possession**. ***"We have a call at four"*** **cannot** — it's the **action-have**
   (an event you hold), which uses do-support and can go continuous (*"we're having a
   call"*), but never *have got*.
2. ***"I'm having lunch with the CEO"*** is possible; ***"I'm having a company car"*** is
   not. The continuous *-ing* works **only** with action-*have* (lunch is an event in
   progress). A car is **possessed**, and possession-*have* never takes *-ing* → *"I **have**
   a company car"*.
3. ***have … have*** — *"Let's **have** a meeting tomorrow, and I **have** breakfast at seven
   first."* *"Make a meeting"* comes from *fazer uma reunião*; *"take breakfast"* from *tomar
   café* — English uses the neutral **have** for both events and meals.

**Spaced review:**
- **(Unit 048)** ***made … rethink*** — *"The board **made us rethink** the plan."* After
  **make** (= force/cause) the next verb is the **base form with no *to*** — *make us
  rethink*, never *"make us to rethink"*. *Let* works the same way (*let us stage*).
- **(Unit 025)** ***used to land*** — *"Every AI decision **used to land** on my desk."*
  *used to +* **base verb** marks a **past habit that is no longer true**. The present
  *"passes/lands"* is wrong because the whole point is *then, repeatedly; not anymore* —
  Portuguese *imperfeito* (*passava*), not the present.

**Recognition drill:**
1. ❌ *"carried out **it**"* → ✅ *"The board hasn't **carried it out** yet."* — *carry out*
   is **separable**, and a **pronoun** object **must** sit **between** the verb and the
   particle. A noun could go either side (*carried out the plan / carried the plan out*), but
   *it* has no choice.
2. ❌ *"look the cost model **into**"* → ✅ *"We need to **look into** the cost model before
   the vote."* — *look into* is **inseparable** (the particle *into* is a preposition that
   holds its object), so nothing ever splits it. Unlike item 1, it can't separate at all —
   noun **or** pronoun stays after *into*.
3. ***put off*** — *"let's **put** the meeting **off** to Thursday."* In a live sync the
   phrasal verb is the natural register; **postpone** is correct but reads formal/written —
   save it for the board brief or the follow-up email.
4. ***on*** — *"pushed back **on** the budget."* *push back on* is **inseparable** (object
   after the preposition → *pushed back on it*). *"Backed down"* is **intransitive** — no
   object at all. Tell them apart by asking whether the verb needs an object and whether the
   small word is a preposition (needs an object → inseparable) or a bare particle.

### 10. 🇧🇷 Resumo em português

**A regra e quando usar.** Um **phrasal verb** é **verbo + partícula** (*out, up, off, on,
into, back…*), e a partícula muda o sentido: *look into* (investigar) ≠ *look after*
(cuidar) ≠ *look up* (procurar). Eles importam porque são como o inglês **realmente fala**:
numa reunião o nativo diz *put it off, call it off, roll it out, cut back on it* — não
*postpone, cancel, implement, reduce*. Os dois estão certos, mas o phrasal verb é o registro
**falado/natural** e o verbo latino é o **formal/escrito**. Usar só o verbo latino (o
cognato — *implement, postpone, cancel*) deixa o inglês correto porém "traduzido", travado.

**As armadilhas.** A pior não é vocabulário, é **ordem da palavra**. Nos separáveis, o
**substantivo** pode ir dos dois lados (*carry out the plan* = *carry the plan out*), mas o
**pronome** (*it, them*) **tem** de ficar **no meio**: *"carry **it** out"* ✅, nunca *"carry
out **it**"* ✗ — o erro nº 1, que vem de *"adiá-lo"*. Já os **inseparáveis** (*look into,
count on, push back on, deal with*) **nunca** se dividem: o objeto vem **sempre depois** da
partícula (*look into it*, não *look it into*). Regra prática: se a palavrinha é uma
**preposição** (*into, on, with*), quase sempre inseparável; se é uma **partícula-advérbio**
(*out, up, off, down*), quase sempre separável — e na dúvida, ponha um **substantivo**
depois da partícula, que é sempre seguro. Se ainda travar entre o verbo latino e o phrasal,
releia `lessons/2026-09-04-unit-054.md` (have) e volte a este arquivo.
